# LaunchDeck 产品需求文档

## 1. 产品概述

LaunchDeck 是一款原生 macOS 应用启动器，用于补充或替代经典 macOS 启动台体验。用户可通过菜单栏入口呼出应用网格，并通过浏览、搜索或键盘操作快速启动应用。

核心目标：用户应能在呼出 LaunchDeck 后的 1～3 秒内找到并启动目标应用。

### 1.1 设计原则

- 原生：遵循 macOS 的视觉、键盘和辅助功能规范。
- 快速：热呼出目标低于 300ms，搜索反馈低于 50ms。
- 安静：可不显示 Dock 图标，空闲时几乎不占用 CPU。
- 可控：用户可调整排序、布局、隐藏项目和文件夹。
- 隐私：应用列表、布局和使用记录默认只保存在本地。

## 2. 目标用户

- 怀念旧版 macOS 启动台的用户。
- 更喜欢浏览应用图标，而不是只使用 Spotlight 的用户。
- 希望自行整理应用布局和文件夹的用户。
- 希望获得更快、更轻量应用启动体验的用户。

## 3. 功能需求

### 3.1 应用发现

默认扫描：

- `/Applications`
- `/System/Applications`
- `~/Applications`

后续支持用户添加和移除自定义目录。每个应用记录名称、Bundle Identifier、URL、图标来源、最近使用时间、使用次数、用户布局位置和隐藏状态。

规则：

- 使用 Bundle Identifier 作为主要稳定标识，缺失时使用标准化路径。
- 去除重复应用，并优先保留用户可直接访问的版本。
- 不展开 `.app` 包内部，避免将辅助程序误识别为独立应用。
- 新安装应用自动出现；卸载或移动后更新索引。
- 图标读取失败时显示统一的默认应用图标。

### 3.2 启动器界面

- 默认铺满当前显示器可用区域，并可恢复为居中窗口。
- 背景使用半透明材质，并兼容浅色和深色模式。
- 应用以图标加名称的自适应网格显示。
- 支持调整图标大小、行列数及是否显示名称。
- 应用数量超过单页容量时支持分页。
- 分页使用可点击的圆点指示器，当前页圆点高亮；拖拽到圆点可跨页移动。
- 触控板双指横向滑动切换页面，并避免一次手势连续跳过多页。
- 页面根据翻页方向滑入和滑出，并带有轻微淡化与弹性缓动。
- 默认使用启动台模式铺满当前显示器；可切换为标准窗口模式。
- 标准窗口模式使用系统红黄绿按钮，支持移动、缩放、最小化和原生全屏空间。
- 背景、搜索栏、分页控件和应用卡片采用分层玻璃材质与高光描边。
- 多显示器环境下默认在鼠标所在显示器打开。
- 分辨率变化或显示器断开时自动重新排布，不丢失布局数据。

### 3.3 打开与关闭

- 菜单栏图标可以显示、隐藏和退出应用。
- 左键菜单栏图标直接显示启动器，右键显示重新扫描和退出菜单。
- 从 Finder 或其他启动器点击 LaunchDeck 图标时直接显示界面；后台运行时再次打开也应显示。
- 按 `Esc` 关闭。
- 点击背景空白处关闭。
- 启动器显示时自动隐藏系统菜单栏和 Dock，移动到屏幕边缘可以临时唤出；关闭后恢复原状态。
- 通知中心或系统浮层出现时保持启动器可见，不因短暂失去焦点而关闭。
- 成功启动应用后自动关闭，可在设置中关闭此行为。
- 支持登录时自动运行。
- 默认作为后台附件应用运行，不持续占用 Dock。

### 3.4 搜索

- 打开后直接输入即可搜索，无需先点击输入框。
- 搜索应用名称、Bundle Identifier 和用户别名。
- 后续支持模糊匹配、拼音全拼及首字母。
- 搜索结果实时更新并自动选中第一项。
- `Return` 启动选中项，方向键改变选择。
- 第一次按 `Esc` 清空搜索，搜索为空时再次按下关闭窗口。
- 后续可结合使用频率和最近使用时间调整结果排序。

### 3.5 启动应用

- 单击应用图标或按 `Return` 启动。
- 应用不可用时显示明确错误，不让界面无响应。
- 外接磁盘中的应用暂时不可用时保留布局位置并显示状态。
- 右键菜单包含“打开”“在 Finder 中显示”“隐藏”和“应用信息”。
- 第一版不提供直接卸载或移到废纸篓，避免误删除。

### 3.6 布局与整理

排序模式：

- 自定义排序
- 按名称排序
- 按最近使用排序
- 按使用频率排序
- 按安装时间排序

自定义模式支持拖拽、跨页移动、固定到首页和自动保存。应用升级后应保持原位置。

文件夹能力在 V1 阶段实现：将一个应用拖到另一个应用上创建文件夹，可重命名、拖入、拖出和内部排序。文件夹只改变 LaunchDeck 内部分类，不移动磁盘上的应用。

### 3.7 设置

常规设置：登录启动、菜单栏图标、Dock 图标、启动后关闭、记住页面。

窗口设置：可选择“启动台模式”或“标准窗口模式”，切换后立即生效。

外观设置：主题、背景材质、图标尺寸、网格密度、名称字号、动画和减少动态效果。

应用来源：管理扫描目录、忽略目录、重新扫描和重建索引。

数据管理：导入导出布局、重置布局和清除使用记录。

## 4. 非功能需求

### 4.1 性能

- 冷启动进入后台不超过 1 秒。
- 热呼出目标低于 300ms。
- 输入后 50ms 内刷新搜索结果。
- 500 个应用下滚动和动画保持流畅。
- 空闲 CPU 使用率接近 0，空闲内存目标低于 100MB。
- 扫描和图标加载不得阻塞主线程。

### 4.2 隐私与安全

- 默认无账号、无遥测、无网络请求。
- 不读取应用包内部的用户内容。
- 数据存储在用户的 Application Support 目录。
- 仅在功能确实需要时申请权限。
- 首版避免依赖辅助功能权限。

### 4.3 可访问性

- 所有应用项具有可读的辅助功能标签。
- 完整支持键盘导航。
- 兼容 VoiceOver、增大对比度和减少动态效果。
- 不只依靠颜色表达选中、错误或不可用状态。

## 5. 异常与边界情况

- 两个应用名称相同但 Bundle Identifier 不同。
- 应用没有 Bundle Identifier 或图标。
- 应用被移动、重命名、升级或卸载。
- 外接磁盘未连接或目录权限失效。
- 布局配置损坏或来自较新版本。
- 系统中存在数百或上千个应用。
- Stage Manager、全屏应用和多显示器同时使用。

## 6. 首版验收标准

1. 首次启动能发现三个默认目录中的常见应用。
2. 菜单栏图标可以显示和隐藏启动器。
3. 输入应用名称并按回车可以启动目标应用。
4. 可以通过键盘或鼠标选择并启动任意可见应用。
5. `Esc` 能先清除搜索，再关闭启动器。
6. 扫描失败或启动失败时界面提供可理解的错误提示。
7. 浅色和深色模式下内容均清晰可见。
8. 扫描不会阻塞界面，500 个应用下搜索无明显卡顿。

## 7. 版本范围

### MVP

应用扫描、网格展示、即时搜索、应用启动、菜单栏入口、基础键盘操作和错误反馈。

### V1.0

持久化自定义排序、隐藏应用、分页和跨页拖动、文件夹、多显示器完善、目录实时监听、外观设置及布局导入导出。

### 后续版本

触控板手势、拼音搜索、多套布局、快捷操作、iCloud 同步、主题和扩展机制。
