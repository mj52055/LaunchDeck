# LaunchDeck

LaunchDeck 是一个原生 macOS 应用启动器，目标是提供接近经典“启动台”的网格浏览体验，同时保留快速搜索和键盘操作。

## 当前能力

- 扫描系统与用户应用目录
- 以自适应网格显示应用图标
- 输入即搜索，支持名称和 Bundle Identifier
- 触控板双指横向滑动翻页
- 拖拽调整顺序，并可拖到分页圆点跨页移动
- 隐藏应用和恢复管理
- 每页 35 个应用的分页显示
- 系统启动台风格的圆点分页指示器
- 排序与隐藏状态自动保存到本地
- 菜单栏入口
- 左键菜单栏图标直接打开，右键显示管理菜单
- 双击应用图标或重新打开后台应用时直接显示启动台
- 点击界面空白区域隐藏到菜单栏
- 全屏显示时自动隐藏系统菜单栏与 Dock，移动到屏幕边缘可唤出
- 通知中心覆盖时保持启动器运行，不会因失去焦点自动关闭
- 可在设置中切换启动台模式与标准窗口模式
- 使用独立原生设置窗口，后台附件模式下也能可靠打开
- 标准窗口模式提供系统红黄绿按钮、窗口缩放和原生全屏
- 默认铺满当前显示器，翻页带方向滑动与淡入淡出动画
- 分层玻璃背景、控件和应用卡片效果
- 触控板右边缘手势避让与轻量化分页渲染
- 使用企鹅抱鱼照片制作的自定义应用图标
- `Esc` 清空搜索或关闭窗口

## 运行要求

- macOS 14 或更高版本
- Swift 6.1 或更高版本
- 不要求安装完整 Xcode，现有 Swift Command Line Tools 即可构建

命令行验证：

```bash
swift build
swift test
```

运行开发版本：

```bash
swift run LaunchDeck
```

生成可双击运行的 `.app`：

```bash
./scripts/build-app.sh
open dist/LaunchDeck.app
```

当前仓库使用 Swift Package，因此无需下载完整 Xcode。生成的本地 `.app` 尚未进行 Developer ID 签名和公证，只适合本机开发测试；正式分发阶段再补充签名、公证和 DMG 打包。
